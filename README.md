# SpaceHub Global — Jekyll

Jekyll version of the SpaceHub Global multilingual blog.

## Included
- Multilingual homepage: English, Español and Português (Brasil)
- Jekyll blog post for the uploaded article:
  **Número Virtual Temporário: Quando Usar, Como Escolher e O Que Considerar**
- Clean `/blog/numero-virtual-temporario/` URL
- Netlify/Jekyll-compatible structure

## Netlify
The repository root can be deployed directly on Netlify. Suggested build settings:
- Build command: `jekyll build`
- Publish directory: `_site`

If Netlify does not already have Jekyll available, add a Ruby/Jekyll build environment or use a Netlify-supported Jekyll configuration.
